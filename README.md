# Demonstração Blend Wine

Conceito comercial exclusivo preparado pela Voragon para mostrar uma possível evolução dos catálogos atuais da Blend Wine.

## Entregáveis

- `index.html`: protótipo navegável e responsivo.
- `apresentacao-blend-wine.mp4`: apresentação visual em vídeo.
- `apresentacao-blend-wine.pdf`: versão estática para compartilhamento.

Produtos, valores e condições exibidos no protótipo são ilustrativos. O conteúdo serve para apoiar uma conversa de descoberta; não representa uma loja oficial em operação nem uma proposta de escopo fechado.

## Abrir localmente

```bash
python3 -m http.server 8765
```

Acesse `http://127.0.0.1:8765`.
